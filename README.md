# WePilot

Un copiloto conversacional de seguridad vial que ayuda a reconocer el cansancio antes de que se transforme en riesgo.

[Ver landing publicada](https://eeminionn.github.io/WePilot/)

## La idea

WePilot acompaña trayectos largos o monótonos mediante interacciones breves, considera el contexto del viaje y recomienda pausas preventivas. No utiliza cámaras ni sensores fisiológicos y cualquier chequeo visual se realiza únicamente con el vehículo detenido.

Estado actual: prototipo en validación.

## Experiencia digital

La landing cuenta la historia del producto como un trayecto: el riesgo, la conversación, la pausa, el modelo para empresas y la visión del equipo. La ruta y el vehículo 3D son geometrías procedurales propias.

## Desarrollo local

```bash
npm install
npm run dev
```
